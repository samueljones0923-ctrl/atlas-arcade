# Atlas Arcade Classic — Polished Release

- Replaced the floating setup window with a true full-screen home page.
- Preserved the fixed desktop game layout: controls on the left, map on the
  right, with no page scrolling during a round.
- Removed floating bordered answer callouts and the post-answer country card
  from live games. Feedback is now a compact line in the left panel.
- Renamed the optional timed ruleset to **Competitive** throughout the
  player interface.
- Reduced the visual weight of Competitive play in setup, gameplay, and
  results so normal geography practice remains the main experience.
- Kept separate fastest-time categories for Locate, Capitals, Flags,
  Map → Name, Mixed Mission, and Spell All.
- Competitive games use all 197 countries, standard mode-specific ordering,
  no hints or skips, and a two-second penalty per mistake.
- Balanced the six game cards on phones and retained the slide-out mobile
  control drawer.
- Kept actual bundled flag artwork, 24× map zoom, local progress, optional
  shared leaderboards, accounts, PWA installation, and offline replay.
